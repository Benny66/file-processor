# 005 — 检查与缩略图

**Blocked by**: 002, 004

**规格**: US-04、US-05、US-07；D-13（部分）、D-15、D-17

## 目标

队列项显示方向正确的缩略图、像素尺寸、体积与状态；损坏、动图、超限文件在检查阶段被可读地标记，不阻塞其它文件。

## 涉及层

- [ ] 数据层：无数据库。
- [ ] 逻辑层：新增 `internal/imageproc` 的检查能力：内容格式探测、EXIF 方向归一后的宽高、字节数、GIF/WebP 动图检测、100 MP/512 MB 上限、96 px 缩略图（base64）；service 提供 `InspectImage`；绑定层错误走 `apperr`。
- [ ] UI 层：队列可见项懒加载检查结果；缩略图、宽高、体积、状态徽标；失败原因展示；失败项可移除；透明缩略图用棋盘格背景。
- [ ] 测试：各输入格式检查；方向缩略图；动图 GIF/WebP；损坏文件；超限；中文路径；前端手动视觉验证。

## 验收标准

- 每个可处理项显示方向正确的缩略图、宽高、源体积与状态。
- 动图、损坏、超限文件标记失败并显示原因；可单独移除；不阻止其它项继续。
- 透明图片缩略图在棋盘格上显示。
- 大量文件时缩略图按可见项逐步加载，界面保持可响应。
- 扩展名与内容格式不一致时按内容格式展示并提示，不判失败。
- 动画检测不静默取首帧。
- `make test` / `make lint` 通过；新依赖已登记；macOS 手动验证通过。
- 不在本切片实现处理与输出。
