# 007 — 宽高上限盒

**Blocked by**: 006

**规格**: US-10、US-23、US-24（无目标体积部分）；D-10、D-25

## 目标

用户可以设置最大宽高，批次输出等比缩放到盒内，不裁切、不拉伸、不放大；在只有尺寸规则时，已达标文件被跳过。

## 涉及层

- [ ] 数据层：无数据库。
- [ ] 逻辑层：`imageproc` 等比适配计算与高质量缩放；service 在批次规则中加入宽高盒；源图在盒内且无格式变更、无目标体积时标记“已达标”且不产出文件；批次汇总统计跳过。
- [ ] UI 层：宽高盒开关与两个输入框；范围 1–65535 校验；队列显示输出尺寸；状态与“已达标”文案；错误提示。
- [ ] 测试：适配数学（横图/竖图/方图/极端比例）；不放大小图；无效输入；已达标跳过；中文路径；前端手动验证。

## 验收标准

- 宽高盒可开启并输入最大宽/最大高；非法值无法开始。
- 输出尺寸等比放入盒内；不裁切、不拉伸；源图小于盒子时不放大。
- 只有尺寸规则时，源图已在盒内且无格式变更的文件标记“已达标”，不产出新文件，不修改源文件。
- 具备格式变更时，缩放与转换同时生效。
- 批次汇总包含跳过数量；失败继续策略不变。
- 目标体积规则尚未实现；体积与尺寸冲突逻辑留给 008。
- `make test` / `make lint` 通过；macOS 手动验证通过。
