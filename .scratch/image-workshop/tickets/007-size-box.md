# 007 — 宽高上限盒

**Blocked by**: 006

**规格**: US-10、US-23、US-24（无目标体积部分）；D-10、D-25

## 目标

用户可以设置最大宽高，批次输出等比缩放到盒内，不裁切、不拉伸、不放大；在只有尺寸规则时，已达标文件被跳过。

## 涉及层

- [x] 数据层：无数据库。
- [x] 逻辑层：`imageproc` 等比适配计算与高质量缩放；service 在批次规则中加入宽高盒；源图在盒内且无格式变更、无目标体积时标记“已达标”且不产出文件；批次汇总统计跳过。
- [x] UI 层：宽高盒开关与两个输入框；范围 1–65535 校验；队列显示输出尺寸；状态与“已达标”文案；错误提示。
- [x] 测试：适配数学（横图/竖图/方图/极端比例）；不放大小图；无效输入；已达标跳过；中文路径；前端手动验证。

## 验收标准

- 宽高盒可开启并输入最大宽/最大高；非法值无法开始。
- 输出尺寸等比放入盒内；不裁切、不拉伸；源图小于盒子时不放大。
- 只有尺寸规则时，源图已在盒内且无格式变更的文件标记“已达标”，不产出新文件，不修改源文件。
- 具备格式变更时，缩放与转换同时生效。
- 批次汇总包含跳过数量；失败继续策略不变。
- 目标体积规则尚未实现；体积与尺寸冲突逻辑留给 008。
- `make test` / `make lint` 通过；macOS 手动验证通过。

## 完成记录

- 状态：完成（2026-10-23）
- 实现说明：
  - 引擎：`imageproc.ProbeImage` 只读格式与方向归一后的尺寸（不整图解码）；`FitWithin` 做等比上限盒计算（不裁切、不拉伸、不放大）；`Convert` 新增 MaxWidth/MaxHeight，方向归一后再 CatmullRom 缩放；输出尺寸随实际缩放结果返回。
  - 批次：`ProcessBatch` 校验宽高需同时设置且在 1–65535；`convertOne` 先探测，源格式与输出格式相同且（盒关闭或已在盒内）时标记 `skipped`/“已达标”，不写文件；盒外或格式变更时缩放/转换并写文件；汇总统计跳过。
  - UI：限制尺寸开关 + 宽高输入（默认 1920×1080）；非法值禁用开始并提示；开始规则改为“格式变更或开启尺寸盒”；请求携带 max_width/max_height；队列在结果出现后显示输出尺寸，跳过行显示“已跳过/已达标”，扩展名 warning 与已达标合并。
  - 契约：BoxMinDimension/BoxMaxDimension 前端镜像加入 `lib/image.ts`，由 parity 护栏校验。
