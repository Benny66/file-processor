# 009 — 单张对比与结果过期

**Blocked by**: 008

**规格**: US-28、US-29、US-30；D-18、D-28

## 目标

用户选中成功项后可以查看原图与结果图的并排或切换对比；预览方向正确、透明可见；参数或队列变化后结果被标记为过期。

## 涉及层

- [ ] 数据层：无数据库。
- [ ] 逻辑层：service 提供 `RenderPreview(path, maxEdge)`，返回 base64、宽高、是否含透明；方向归一；限制最大预览边长；错误走 `apperr`；不为任意路径开放 HTTP 静态服务。
- [ ] UI 层：对比对话框/并排或切换；两侧尺寸与体积；加载与错误状态；透明棋盘格；参数或队列变化时显示“结果已过期”；开始新批次清除旧状态；不做缩放/拖拽/像素级检查。
- [ ] 测试：预览尺寸与方向；透明预览；绑定错误；结果过期状态；前端手动视觉验证。

## 验收标准

- 选中成功项后可打开对比，原图与结果图均可见，并显示两侧尺寸与体积。
- 预览按方向归一后的像素显示；透明图用棋盘格背景。
- 预览经绑定返回 base64，不通过本地 HTTP 暴露文件路径。
- 参数或队列变化后，已有结果标记“结果已过期”；开始新批次后清除旧状态。
- 首版不做缩放、拖拽、滑动对比与像素级检查。
- `make test` / `make lint` 通过；macOS 手动视觉验证通过。
