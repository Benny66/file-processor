# 010 — 预设与上次设置

**Blocked by**: 008

**规格**: US-12、US-13；D-19

## 目标

用户可以把当前参数保存为命名预设，支持创建、应用、重命名、删除并跨重启持久化；应用重启后恢复上次使用的参数。

## 涉及层

- [ ] 数据层：新增 `ImagePreset` 模型（`BaseModel`、唯一名称、输出格式、目标体积、最大宽/高）并登记 `AllModels()`；SQLite 迁移；`config.json` 增加上次处理参数字段。
- [ ] 逻辑层：service 提供预设 CRUD、名称去空白与唯一性校验、参数校验；`ListPresets` 返回 `page.Result`；`SaveImageSettings` / `GetImageSettings` 读写配置；绑定层错误走 `apperr`。
- [ ] UI 层：预设下拉与管理对话框；保存当前参数为预设；应用预设只改参数、不自动开始；重命名/删除；校验错误展示；启动时恢复上次参数；配置损坏时回退默认值且不阻断启动。
- [ ] 测试：真实 SQLite 的 CRUD（不用 mock）；名称唯一；上次设置往返；损坏配置回退；前端手动验证。

## 验收标准

- 预设可创建、应用、重命名、删除，跨重启保留；名称去空白后不可重复。
- 应用预设只更新参数，不自动开始处理；已有结果标记过期。
- 应用重启恢复上次使用的参数；配置缺失或损坏时回退默认值，不阻断启动。
- `ListPresets` 使用分页契约；新模型已登记；依赖无需新增。
- 不实现任务历史、批量重跑或失败重试队列。
- `make test` / `make lint` 通过；macOS 手动验证通过。
