# 三平台交付，银河麒麟为一等公民

应用需要覆盖用户实际所在的银河麒麟桌面操作系统 V10 SP1（2203，x86_64），同时保留 macOS 开发环境与 Windows 交付。决定：macOS、Windows、Kylin 三平台都是一等目标——Kylin 不能只做到“能编译”，必须有可安装产物与冒烟验证。

**后果**：Wails 不支持从 macOS 交叉编译 Linux，Kylin 需要独立的 Linux 构建环境；Linux 的 WebKit/GTK 依赖、.deb 打包与兼容性验证因此进入主链路。相比之下只交付 Kylin 或只做不承诺平台的二进制会省很多工作，但无法保证目标环境的真实可用性。
